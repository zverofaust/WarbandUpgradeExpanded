# Warband Upgrade Expanded

Compatibility submod project for Total War: Warhammer III and Warband Upgrade Ultimate (Steam Workshop 2853239091).

## Status

Initial development. No playable `.pack` has yet been generated or validated. Database schemas, upgrade-group semantics, and UI links must be checked before packaging.

## Principles

- Keep the original Workshop mod installed and unmodified.
- Add or remove upgrade paths using existing game units and assets.
- Keep requested changes in human-readable source files.
- Do not redistribute the original Workshop mod's assets.

See `data/changes/tomb_kings.json` for the first requested changes.
